# Инфраструктура

`alisa-reminders.service` — шаблон systemd для постоянно работающей
службы напоминаний. Настройка описана в [REMINDERS.md](../REMINDERS.md).
Шаблон подготовлен, на внешней машине служба автоматически не установлена.

`alisa-server.service`, `alisa-telegram.service` — сервер и бот на
отдельном ПК с Ubuntu. `alisa-update.sh` с `alisa-update.service` и
`alisa-update.timer` — автообновление из git в тишине с откатом. Как
ставить и как это устроено — [MIGRATION.md](../MIGRATION.md).

## SearXNG для VDS (пока не используется)

Здесь лежит конфиг SearXNG — своего поискового движка без аккаунтов и тарифов.
Он рассчитан на твой VDS с Ubuntu, где Docker родной. На рабочий ПК Docker
и WSL не ставим.

Пока не трогаем: на шаге 2 поиск работает локально через `ddgs`, а SearXNG
подключаем на шаге 3 и сравниваем оба бэкенда прогоном `tests/questions.yaml`.

Когда дойдём до VDS, помни: там уже живут телеграм-боты, VPN и скрипты.
Контейнер слушает только `127.0.0.1:8080`, в общие порты и в системные
настройки не лезет, трогать существующее не нужно.
