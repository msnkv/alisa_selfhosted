# Как запустить: шпаргалка

Порядок: сначала сервер на ПК, потом бот и спутник — оба ходят к серверу.

## 1. Сервер на ПК

PowerShell, из папки проекта:

```
.\alisa.ps1 --serve
```

Или из cmd:

```
alisa.bat --serve
```

Слушает порт 8765. Окно не закрывать: закрыл — бот и спутник замолчат.
После правки кода на ПК сервер перезапустить — спутник подтянет новый код сам.

## 2. Telegram-бот на ПК

Отдельное окно, из папки проекта, пока сервер уже работает:

```
.venv\Scripts\python.exe -m assistant.telegram_bot
```

Токен бота и разрешённые ID — в `.env`, адрес сервера — `server.url`
(без него `localhost:8765`, на самом ПК это и нужно). Подробности — в
[TELEGRAM.md](TELEGRAM.md). Запускать одну копию: две на одном токене
мешают друг другу.

## 3. Спутник на ноутбуке

cmd:

```
cd /d C:\alisa_selfhosted
client.bat
```

Адрес сервера берётся из `config.local.yaml` на ноуте
(`server.url: "192.168.31.35:8765"`). Указать руками:

```
client.bat 192.168.31.35:8765
```

Перед стартом `client.bat` сам сверяет код с сервером и обновляется.
Ctrl+C во время ответа — отменить ответ.
