# Telegram-клиент Алисы

Отправляешь боту текст или голосовое — он отправляет вопрос серверу Алисы
и возвращает **текст и отдельное голосовое сообщение**. Распознавание,
DeepSeek и Silero работают на сервере. На машине бота нужны только Python
3.10+ и три пакета из `requirements-telegram.txt`, модели не нужны.

## Настройка

1. Создай бота через [@BotFather](https://t.me/BotFather), команда `/newbot`.
   Его токен запиши в `.env` в корне проекта:

   ```dotenv
   TELEGRAM_BOT_TOKEN=сюда_токен_от_BotFather
   TELEGRAM_ALLOWED_USER_ID=
   ```

   Если `.env` уже существует, добавь эти строки, сохранив другие ключи.
   Для самого бота ключ DeepSeek не нужен.

2. В `config.local.yaml` укажи адрес сервера из
   `config.local.yaml.example` (если адрес ПК поменялся, поправь):

   ```yaml
   server:
     url: "192.168.31.35:8765"
     # token: "тот же токен, что задан у сервера"  # если включён
   ```

   Адрес читается из `server.url`: сначала `config.yaml`, затем поверх
   него `config.local.yaml`. Без адреса используется `localhost:8765`,
   что подходит, если бот работает на самом сервере.

3. На Windows из корня проекта:

   ```powershell
   py -3.10 -m venv .venv
   .venv\Scripts\python.exe -m pip install -r requirements-telegram.txt
   .venv\Scripts\python.exe -m assistant.telegram_bot
   ```

   Если `.venv` уже есть, используй его, создавать заново не нужно.
   На macOS/Linux:

   ```sh
   python3 -m venv .venv
   .venv/bin/python -m pip install -r requirements-telegram.txt
   .venv/bin/python -m assistant.telegram_bot
   ```

4. Напиши боту `/start`. Он покажет твой числовой Telegram ID.
   Впиши его в `TELEGRAM_ALLOWED_USER_ID` в `.env`, останови бота
   через Ctrl+C и запусти снова. Теперь можно писать и слать войсы.
   Пока ID не задан, доступа к Алисе нет. Бот работает только в личном
   чате с указанными пользователями.

   Пустить ещё кого-то — дописать ID через запятую:
   `TELEGRAM_ALLOWED_USER_ID=375226760,1049500895`. У каждого свой
   разговор и своё «забудь», но `data/` общая: допущенный может спросить
   про всё, что там лежит. Первый ID — владелец, только ему служба
   напоминаний доставляет напоминания.

На ПК с моделями должен работать сервер: `alisa.bat --serve`.
Бот получает сообщения через long polling: публичный адрес и входящие
порты ему не нужны. Машина бота должна иметь доступ и к Telegram,
и к адресу Алисы — обычно это тот же ПК или другая машина домашней сети.
При переносе бота на VPS потребуется связь с домашней сетью, например VPN.
У одного токена должна работать одна копия бота; существующий webhook
бот автоматически не отключает.

## Поведение

- Текст отправляется на `/ask` как JSON, голосовое — исходным OGG.
- WAV из ответа конвертируется в OGG/Opus через PyAV и отправляется
  методом [sendVoice](https://core.telegram.org/bots/api#sendvoice).
  Отдельно устанавливать FFmpeg не нужно — библиотеки входят в колёса PyAV.
- Длинный текст разбивается на сообщения; звук приходит одним войсом.
- Если сервер выключен или не смог ответить, бот сообщает об этом текстом.
  Если сервер не прислал звук, текст всё равно доставляется.
- Лимит входящего голосового — 8 МиБ, как у сервера.
- Текст и голосовые одного чата используют сессию `telegram:<chat_id>`.
  «Забудь» сбрасывает только этот разговор; история браузера и спутника
  сохраняется. Режим сказок и группировка записей в журнале тоже раздельные.
- Сессии хранятся в памяти сервера: его перезапуск сбрасывает разговоры.
  Неактивные сессии удаляются через сутки; сервер хранит до 128 сессий.
  Для разделения нужно обновить и перезапустить сервер и клиентов,
  а страницу браузера перезагрузить. Подробнее — [README.md](README.md).
- При перезапуске обрабатываются неподтверждённые сообщения Telegram.
  Как и у обычного polling-клиента, остановка между обработкой и
  подтверждением update может привести к повторной обработке.

## Проверка без ключей

```sh
python -m unittest discover -s tests -p test_telegram_bot.py -v
```

Тесты используют локальный HTTP-сервер вместо Telegram и Алисы,
но реально передают JSON, OGG и multipart с ответным войсом.
Результат кодирования проверяется декодированием Opus.
Живой обмен с Telegram и серверными моделями требует твоих настроек.
