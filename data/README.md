# Личные данные ассистента

Сюда кладутся файлы `.md` с тем, что ассистент должен знать про меня:
раскладка вещей, рецепты, записи, что угодно.

Как это работает:

- Берутся все файлы по маске `*.md` из этой папки. Файл с другим
  расширением ассистент не увидит.
- Содержимое целиком уходит в системный промпт. Файлы маленькие, поиск
  по фрагментам не нужен, а у модели контекст на миллион токенов.
- После правки файла перезапускать ничего не надо: ассистент сверяет
  время изменения перед каждым вопросом.
- Сохранять в кодировке UTF-8.
- Если в файле используются сокращения или коды мест (например `Л-Н-3`),
  опиши их расшифровку в самом файле. Ассистенту велено читать такие
  коды словами, но понять их он может только из твоего описания.

## Файл about.md — особый

`about.md` — это сведения о самом владельце: кто он, кто живёт в доме,
чего не ест, что уже есть из техники, как с ним разговаривать. Ассистенту
велено учитывать его **всегда**, а не только когда спрашивают про
владельца: от этого зависит, что вообще стоит советовать. Вслух он его не
пересказывает.

Самый полезный раздел там — про еду: аллергии и то, чего человек не ест,
меняют каждый совет по готовке.

## Куда уходит содержимое

В git файлы не попадают - папка в `.gitignore`, кроме этого README. С
машины они тоже никуда не уезжают сами.

**Но при каждом вопросе всё это отправляется в API DeepSeek** как часть
системного промпта. Так работает ассистент: модель удалённая. Поэтому
паролям, номерам карт и документам тут не место. Всё остальное — на твоё
усмотрение, но знать об этом надо.
